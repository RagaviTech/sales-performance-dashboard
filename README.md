# Sales Performance Dashboard

## Project Overview

This project is an interactive Sales Performance Dashboard created using Microsoft Power BI.

The dashboard helps users understand sales performance through interactive visuals and region-based filtering.

## Features

* Total Sales overview
* Region-based filtering
* Interactive charts and visuals
* Sales performance analysis
* Clean and user-friendly dashboard design

## Tools Used

* Microsoft Power BI
* Power Query
* Data Visualization

## Project File

The `.pbix` file included in this repository is the Power BI dashboard project file.

## Purpose

The purpose of this project is to analyze sales data and present useful insights through an interactive dashboard.
